# Ask Before Using Workarounds

When the standard approach to fix an error doesn't work, **STOP** before trying alternative solutions.

## Process

1. **Attempt** the straightforward fix
2. **If it fails**, explain why it didn't work
3. **Propose** the alternative approach with reasoning
4. **Wait** for explicit permission before proceeding

## What Requires Permission

- Workarounds that deviate from standard patterns
- Fixes that feel "hacky" or unusual
- Solutions that have trade-offs or side effects
- Approaches you're not confident about

## Never

- Chain multiple failed attempts without stopping
- Apply workarounds silently
- Assume unconventional = acceptable
