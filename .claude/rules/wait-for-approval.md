# Wait for Explicit Approval

When proposing a plan or approach, **DO NOT** start executing it automatically.

## Process

1. **Present** the plan or proposal
2. **Wait** for explicit approval ("do it", "go ahead", "yes", etc.)
3. **Only then** execute

## What Counts as Approval

- "Do it", "Go ahead", "Yes", "Proceed", "Execute", "Make it so"
- Explicit confirmation of the proposed approach

## What Does NOT Count

- Asking a question about the plan
- Silence / no response
- "What do you think?" or similar
